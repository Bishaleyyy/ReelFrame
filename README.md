## ✨ About the Project

**ReelFrame** is a lightweight, browser-based media editing tool designed to help creators prepare photos and videos for different social media platforms.

Adjust aspect ratios, preview your media, customize backgrounds, and export your creations—all through a simple interface without installing traditional editing software.

## 🚀 Features

- 🖼️ **Photo & Video Upload** — Import media directly from your device.
- 📐 **Multiple Aspect Ratios** — Choose from 9:16, 16:9, 1:1, and 4:5.
- 🎯 **Fit & Crop Modes** — Adjust how your media appears inside the frame.
- 🎨 **Background Customization** — Choose background colors to complement your content.
- 📤 **PNG Export** — Save edited photo compositions as PNG images.
- 🎥 **Video Export** — Record and export video compositions using browser-supported media APIs.
- 👀 **Live Preview** — Preview your composition while making adjustments.
- 🌐 **Browser-Based** — No traditional software installation required.
- 💻 **Responsive Interface** — Designed for convenient use in a web browser.

## 📖 How to Use

1. Open the [ReelFrame website](https://bishaleyyy.github.io/ReelFrame/).
2. Upload a photo or video from your device.
3. Select your preferred aspect ratio.
4. Choose Fit or Crop mode.
5. Customize the background to match your design.
6. Preview your composition.
7. Export your image or video using the available export option.

## 💻 Run Locally

No build tools or package installation are required.

1. Clone the repository:

   ```bash
   git clone https://github.com/Bishaleyyy/ReelFrame.git
   ```

2. Open the project folder:

   ```bash
   cd ReelFrame
   ```

3. Open `index.html` in your browser, or use the VS Code Live Server extension.
